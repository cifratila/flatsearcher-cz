# FlatSearcher CZ

Czech BUY flat catalog and watcher helpers for **Praha (incl. Karlín), Děčín, and Ústí nad Labem**.

## Scope
- Layouts: 1+kk through 4+1
- Ownership: osobní only
- Exclude: přízemí / suterén / atypical underground
- Flag (do not exclude): mezonet / internal stairs
